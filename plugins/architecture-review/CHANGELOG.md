# Changelog

All notable changes to the `architecture-review` plugin. Format: [Keep a Changelog](https://keepachangelog.com/); versions: [SemVer](https://semver.org/).

## [1.0.0] - 2026-10-22

### Added
- Initial release: `architecture-reviewer` and `architecture-reviewer-lite` agents.
- Boundary model generalized: reviews whatever boundaries the target repo declares (architecture skills + CLAUDE.md + repo tooling) instead of a fixed layering.
- Dependency on `engineering-paved-path` for the architecture skill vocabulary.
